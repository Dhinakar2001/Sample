# Fuel EU Maritime — Assignment Scaffold (NO IMPLEMENTATIONS)

This repository contains a **scaffold** for the Full-Stack developer assignment. It is intentionally **implementation-free** — only folder structure, templates, and documentation files required by the assignment are included so you can paste directly into your GitHub repository and continue implementing locally.

## Included
- `frontend/` — React + TypeScript + Tailwind scaffold (placeholders)
- `backend/` — Node.js + TypeScript + PostgreSQL scaffold (placeholders)
- `AGENT_WORKFLOW.md`, `REFLECTION.md`, plus top-level README and .gitignore
- Scripts (`npm run dev`, `npm run test`) are stubbed in `package.json` files; they print guidance.

## Usage
1. Download the zip and extract.
2. Commit to a GitHub repo as required by the assignment.
3. Implement the code inside `frontend/` and `backend/` following the given architecture.
